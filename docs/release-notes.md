The first source-faithful SetSawa data release preserves **77 PDFs, 149 pages and all 3,966 source rows**, with **3,963 distinct content records** and a reversible mapping for three duplicate pairs.

Download `setsawa-v1.0.0.zip` for the full dataset, original PDFs, schemas, examples, notebook, workbook and report. The Excel workbook and portable HTML quality report are also available separately. `release-checksums.sha256` checks the downloadable assets; `checksums.sha256` checks the package contents.

Validation includes per-document row/score reconciliation, schema and provenance checks, CSV/JSON/Parquet/Excel equivalence, a second full PDF rebuild, adversarial parser/output tests, visual samples from every province and a dependency audit. Exact evidence and limitations are in the package's reports and documentation.

**Extraction accuracy does not verify the source claims, establish wrongdoing, or prove identity.** The source's status wording is retained as a claim. Existing masks are unchanged and masked identifiers are not unique keys.

Project code is MIT. Source-data reuse terms are unspecified. Website crawling, Vercel website implementation and tribute wording are deferred.
