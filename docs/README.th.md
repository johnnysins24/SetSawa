# SetSawa — คู่มือภาษาไทย

ชุดข้อมูลนี้ถอดจากเอกสาร **รวมมิตรท้องถิ่น 68** ที่ได้รับ จำนวน **77 ไฟล์ 149 หน้า** มี **3,966 แถวต้นทาง** และ **3,963 ระเบียนหลังรวมแถวที่มีเนื้อหาซ้ำกันทุกช่อง**

> การตรวจสอบนี้ยืนยันความถูกต้องของการถอดและจัดรูปแบบข้อมูล ไม่ได้ยืนยันข้อกล่าวอ้างในเอกสารหรือความผิดของบุคคล สถานะ “ยืนยันแล้ว” เป็นข้อความจากผู้จัดทำเอกสารต้นทาง ไม่ใช่การรับรองจากโครงการนี้ ชื่อคล้ายกันหรือรหัสที่ปิดบังบางส่วนอาจเป็นคนละคน

## เลือกไฟล์ใช้งาน

- **อ่านด้วย Excel:** [setsawa.xlsx](../data/processed/reader/setsawa.xlsx) มีคำอธิบายภาษาไทย ตัวกรอง และตารางอ้างอิงต้นทาง
- **พัฒนาโปรแกรม:** [CSV](../data/processed/clean/records.csv), [JSON](../data/processed/clean/records.json), [Parquet](../data/processed/clean/records.parquet)
- **ตรวจต้นฉบับ:** [PDF](../data/raw/pdfs/) และ [provenance](../data/processed/clean/provenance.csv) ซึ่งระบุไฟล์ หน้า แถว และค่า SHA-256
- **ดูวิธีการและผลตรวจ:** ดาวน์โหลด [รายงาน HTML](../reports/quality-report.html) แล้วเปิดในเบราว์เซอร์

## ความหมายของตาราง

`records` คือระเบียนเนื้อหาไม่ซ้ำ ส่วน `provenance` เก็บครบทุกแถวต้นทาง โดยเชื่อมกันผ่าน `record_id` ตาราง `duplicates` แสดงการรวมแถวซ้ำทั้งสามคู่ ไม่มีแถวต้นทางถูกทิ้ง

ห้ามใช้ `masked_id` เป็นคีย์ไม่ซ้ำ เพราะมีค่าซ้ำระหว่างคนที่ชื่อไม่ตรงกัน โครงการรักษารูปแบบการปิดบังเดิม ไม่ค้นหาหรือคาดเดาตัวเลขที่ปิดบัง

ชื่ออำเภอต้องอ่านร่วมกับจังหวัด ชื่อหน่วยงานต้องอ่านร่วมกับจังหวัดและอำเภอ รหัสกลุ่มที่สร้างขึ้นไม่ใช่รหัสทางราชการ กรุงเทพมหานครและพังงามีเอกสารที่ระบุว่าไม่มีรายการ จึงยังปรากฏในตารางจังหวัด

คอลัมน์ “สถานะ” ใน PDF มีสองช่อง: `source_status_text` คือช่องแรก และ `source_verification_status_text` คือช่องสุดท้าย ส่วน `source_location_basis_text` คือคำอธิบายการยืนยันหน่วยงาน/พื้นที่จากต้นทาง

ปีของชุดข้อมูลคือ **2568 พ.ศ. / 2025 ค.ศ.** ไม่ใช่วันที่สร้าง PDF หรือวันที่ประมวลผล การรวมคะแนนเป็นผลรวมของค่าที่เอกสารรายงาน ไม่ใช่การยืนยันคะแนนสอบจริง

## ทำซ้ำและข้อจำกัด

ขั้นตอนสร้างข้อมูลซ้ำอยู่ใน [README](../README.md#rebuild) ใช้ Python 3.12 และ uv ข้อมูลและชื่อคอลัมน์สำหรับโปรแกรมมีสัญญารูปแบบอยู่ใน [schemas](../schemas/)

ต้นทางไม่ได้ระบุใบอนุญาตใช้ข้อมูลที่ยืนยันได้ ใบอนุญาต MIT ครอบคลุมเฉพาะโค้ดของโครงการ การให้เครดิตเพิ่มเติมเลื่อนไว้ก่อนตามคำขอ รายการอ้างอิงไฟล์ต้นทางยังคงอยู่ครบ

เว็บ Vercel จะพัฒนาในขั้นตอนถัดไป โดยใช้ชุดข้อมูลที่ผ่านการตรวจและอ้างอิงต้นทางได้
