# Source data reuse terms

The supplied PDFs and transcribed source contents have **unspecified reuse terms**. No explicit source-data license has been established. Their public availability is not represented here as permission to grant an open-data license.

The root MIT license applies to project-authored code only. It does not relicense the PDFs, names, source claims, source contents, or any upstream compilation rights. Dataset schemas and documentation describe the source and transformations without claiming ownership of upstream material.

Technical provenance is preserved. Tribute wording is deferred at the request of the project owner. If applicable source terms are later supplied, record the source of those terms and publish a versioned documentation update.
